# InterviewAI

A placement-preparation platform for CS students: company-wise hiring rounds and
sample papers, mock tests, DSA practice, resume matching and an AI interview coach.

## Status
- [x] Landing page (HTML5, CSS3, JavaScript) in `frontend/`
- [ ] Backend (Python)
- [ ] React app
- [ ] Mock tests, DSA practice, resume ATS match, AI coach

## Run the landing page
Open `frontend/index.html` with VS Code Live Server.
